## ✨ Pro Master Features

1. **🧠 Multi-Stage Smart Keyword Fallback**:
   - If a scene keyword returns 0 clips, the system automatically expands and tries alternative keywords from the sentence (noun pairs, related objects, thematic topics, and cinematic nature terms).
   - Shows a badge indicating which fallback keyword was matched (`🎯 Matched via: '...'`).
   - You will never be left with an empty or broken scene!

2. **🚫 Zero Repeated Clips Guarantee**:
   - Every single scene in your video gets a completely unique video clip or photo.
   - Even if multiple scenes share the same search keywords (e.g., *ocean sunset*), each scene receives a distinct asset.

3. **🎥 Human-Pro Cinematic Video Quality**:
   - **Ken Burns Motion Effect**: Photos are animated with subtle, slow, cinematic zoom (`1.15x`) so still images feel like living documentary footage.
   - **Smooth Scene Transitions**: Subtle 0.35s cinematic crossfade/fade transitions between scenes. No abrupt cuts!
   - **Studio Lower Thirds**: High-contrast, frosted glass subtitle banners with soft drop shadow for maximum legibility.
   - **Sleek Scene Badges**: Numbered corner badges (`#01`, `Scene 01`, `01`) with neon cyan accents.
   - **H.264 FastStart**: High-bitrate video encoding optimized for instant playback.

4. **⬇️ Instant In-Browser Preview & Downloads**:
   - In-browser video player to watch the video immediately.
   - One-click **Download Merged Video (.mp4)**.
   - One-click **Download Numbered Clips (.zip)** for external editing.
